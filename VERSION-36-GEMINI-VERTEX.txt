VERSION 36 - Gemini through Google Cloud Vertex AI

- Gemini (default gemini-3.8-flash) is called through Vertex AI instead of an AI Studio
  API key, so usage is paid from the Google Cloud free-trial credit.
- The browser sends requests to server.py (POST /gemini). The server signs in with the
  same service-account key file as Document AI and calls Vertex AI generateContent.
- Settings > Google Gemini (Vertex AI): Model + Vertex AI location (default global).
  The API key field is removed. Test Connection tests Gemini.
- Service account needs the "Vertex AI User" role; the Vertex AI API must be enabled.
- Automatic retry on 429/503; Google error messages are shown as-is.
- Pages load js/app.js?v=36. Everything else unchanged.
