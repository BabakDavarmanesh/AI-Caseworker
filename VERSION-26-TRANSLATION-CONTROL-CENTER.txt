VERSION 26 - Translation Control Center (Translation Engine redesign)

Visual redesign only. Translation logic, API calls (callGPT), stored data
(localStorage translations), language list (TX_LANGUAGES) and all handlers
(startTranslation, viewTranslation, deleteLangTranslation, clearAllTranslations,
closeTxViewer, exportTranslations) are unchanged. All existing element IDs are kept.

Added
- Header subtitle.
- Summary bar: Total languages, Completed, Translating, Pending (+ "Needs retry",
  shown only when a language has failed questions). Computed from stored state.
- Flow: Source Questions -> AI Translation Engine -> Target Languages. Lights up while
  translating; a small glowing dot travels from the engine to the language card each
  time a question finishes (real events, not a timer).
- Active Language Spotlight (the existing #tx-progress-wrap, restyled): flag with soft
  pulse, real progress (questions done / total), percentage.
- Card states: Pending / Translating / Complete / Error with Translate, "Translating…",
  Re-translate (+ view, delete) and Retry (+ view, delete).
- Staggered fade-up on first load, hover lift, success animation on completion.
- Very faint globe/orbit motif behind the control center.
- Responsive: flow becomes vertical when its box is narrow (container query); cards stack.

JavaScript changes (js/app.js)
- renderTranslationEngine(): new markup/state classes (same function name and call sites).
- startTranslation(): 3 small hooks (mark active language, update progress/dot, mark
  just-completed). The translation loop itself is untouched.
- New helpers: txLangState, txRenderSummary, txSpotlightStart, txUpdateActiveProgress,
  txSendFlowDot.

Also fixed
- .main { min-width: 0 } so tablet widths no longer scroll sideways
  (this also affected Question Engine).
