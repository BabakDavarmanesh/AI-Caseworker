⚙️ Settings

Demo mode: Google settings (Document AI, Gemini, voice and avatar) are saved to config.js in this folder.

🔍 Google Document AI
Recommended processor: Document OCR or Layout Parser · Calls go through the local server (Google needs a service-account sign-in, not an API key).
🧠 Google Gemini (Vertex AI)
Runs on Google Cloud Vertex AI with the same Project ID and service-account key file as Document AI — no API key, paid from your Google Cloud credit. The service account needs the Vertex AI User role. Click Test Connection below to check it.
🗣️ Interview Voice — Google Gemini
Speaks interview questions in every interview language (English, Persian, French, Arabic…). Uses Google Cloud Text-to-Speech with the same Project ID and key file as Document AI; the service account needs Agent Platform User (already added) and the Cloud Text-to-Speech API must be enabled.
🧑‍💼 Gemini Live Avatar — Virtual Caseworker
The avatar that asks the Question Engine questions on the Virtual Caseworker page. Uses the Google Project ID and service-account key file above.
The avatar model is not available in "global" for this project.
