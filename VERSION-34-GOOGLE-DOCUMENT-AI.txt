VERSION 34 - Google Document AI replaces Azure Document Intelligence

- Uploaded documents are read with Google Document AI. Azure Document Intelligence
  is removed completely: its code, Settings card, and its endpoint/key in config.js.
- Settings: "Google Document AI" card (Project ID, Location us/eu, Processor ID,
  service-account key file name) with a "Test Google Sign-in" button.
- server.py: new POST /google-docai (forwards {skipHumanReview, rawDocument:{mimeType,
  content}} to Google's :process endpoint) and POST /google-docai/status.
  Sign-in order: key file in this folder -> GOOGLE_APPLICATION_CREDENTIALS -> gcloud CLI.
  Works with Document OCR (document.text) and Layout Parser (documentLayout blocks).
- start-ai-caseworker.bat installs google-auth and requests.
- Pages load js/app.js?v=34 so browsers pick up the new code.
- Azure OpenAI, Azure Speech and the avatar are unchanged.
